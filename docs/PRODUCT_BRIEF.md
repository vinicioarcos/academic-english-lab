# Product Brief — Academic English Lab

## Problema

El aprendizaje de inglés académico suele ser genérico, desconectado del trabajo real de un docente e investigador. El usuario necesita practicar frases, vocabulario y estructuras que usa en clases, papers, conferencias y análisis econométrico.

## Solución

Una plataforma web personal conectable a IA para organizar gramática, vocabulario y cuadernos de práctica bajo demanda.

## Principios pedagógicos

- Explicación simple en español.
- Regla clara.
- Ejemplos académicos.
- Escritura activa.
- Corrección inmediata.
- Repetición espaciada.
- Registro de errores frecuentes.

## Público inicial

Docentes universitarios, economistas, investigadores y científicos de datos hispanohablantes.

## MVP

- Dashboard.
- Gramática.
- Vocabulario.
- Biblioteca.
- Cuadernos.
- Práctica activa.
- API route simulada para generación de cuadernos.

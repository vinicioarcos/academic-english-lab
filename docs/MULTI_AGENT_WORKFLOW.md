# Flujo multiagente recomendado

## Herramientas
- Antigravity: orquestación y flujos largos.
- Codex: implementación técnica y depuración.
- Claude: arquitectura, pedagogía y revisión profunda.
- Gemini: generación amplia de contenido, vocabulario y ejercicios.

## Regla de oro
Un agente implementa. Otro revisa. Otro documenta. Si todos implementan a la vez, el repositorio se vuelve carnaval.

## Flujo diario sugerido
1. Elegir una tarea de TASKS.md.
2. Pedir a Claude que refine el alcance.
3. Pedir a Codex que implemente.
4. Pedir a Gemini que genere contenido semilla si aplica.
5. Usar Antigravity para coordinar build, revisión y documentación.
6. Actualizar CHANGELOG.md.

## Orden recomendado por fase

### Fase 1: MVP funcional
Codex lidera. Claude revisa. Gemini apoya con seed data. Antigravity coordina.

### Fase 2: motor pedagógico
Claude lidera diseño pedagógico. Codex implementa. Gemini genera variaciones.

### Fase 3: IA real
Codex implementa API. Claude diseña prompts. Gemini prueba variantes. Antigravity valida flujo completo.

### Fase 4: producto vendible
Claude y Gemini ayudan con contenido. Codex endurece arquitectura. Antigravity coordina pruebas y despliegue.
